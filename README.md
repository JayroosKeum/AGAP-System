# AGAP

Initial project folder scaffold for the existing AGAP PHP and MySQL application.

## Development rules

- Composer is not required or used.
- Load project classes and libraries through explicit PHP `require_once` statements.
- Store manually installed third-party PHP libraries under `backend/libs/`.
- Audit and reuse the existing implementation.
- Do not create a parallel workflow or replace working behavior without tracing the current process first.
